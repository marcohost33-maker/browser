# archiv · browser

**Archiv-Konvention.** Hierher kommen superseded / veraltete Artefakte, die aus dem aktiven
Baum raus sollen, aber NICHT geloescht werden duerfen (Provenienz).

- **Was:** abgeloeste Specs / Docs / Skripte / Datensaetze.
- **Wann:** sobald ein Artefakt durch eine neue Version ersetzt ist.
- **Wie:** Unterordner `YYYY-MM-DD_<slug>/`; Original-Pfad + Grund im Commit-Text.
- **Nicht hierher:** Secrets, personenbezogene Daten.
